# Security

Use GitHub's private vulnerability reporting for exploitable issues:
[report a vulnerability](https://github.com/closure-labs/finite/security/advisories/new).
Include the affected image digest/profile, reproduction steps and impact.
Do not post credentials, private keys or personal workstation data in public issues.

Finite is a personal desktop image. Published channels receive automated image
updates; Home Manager application updates remain manual. Security findings are
triaged by exploitability and reachability, with exact-digest exceptions reviewed
and time limited. There is no guaranteed response or patch deadline.

See [implementation and operating guidance](docs/security-implementation.md) and
[CI security controls](docs/ci-and-releases.md#image-vulnerability-gate).
