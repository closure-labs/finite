# Archive

Finished experiments and dated evidence kept for reference. Nothing here is
run by CI, imported by live code, or validated by `just check`; paths inside
these files may point at locations that no longer exist.

- `workflows/`: retired benchmark workflows and the Doppler OIDC pilot.
- `scripts/`, `tests/`: helpers and tests that only served those workflows.
- `evidence/`: dated JSON evidence referenced by the reports in `docs/`.
